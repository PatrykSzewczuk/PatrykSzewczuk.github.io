Selected software projects.

04

NotifyF1

A personal Formula 1 learning project that tracks a driver's race position and sends a phone notification when it changes. It started as a SwiftUI iOS app, then became a Python notifier using Pushover.

Development stopped when the live-data API removed the free access the project relied on. The code is kept as an inactive portfolio project.

GitHub
05

F1 Race Result Scraper

A Python scraper for Formula 1 race results from the 2025 season. It collects driver standings from each race and saves the results as individual JSON files, skipping empty or future races.
